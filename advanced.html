进阶篇把 SOP 沉淀为 Skill

你反复在干的那类活，值得固化成一个 Skill，下次一句话调用。

沉淀路径

  • 写下标准流程（SOP）
  • 整理成 SKILL.md：何时用、怎么做、注意什么
  • 放进技能库，复用 + 迭代
说明除了自写，也可以把书和视频「蒸馏」成可执行 Skill。
进阶篇多 Agent 协作工作流

复杂项目拆给多个专家 Agent 并行，再由一个总控汇总，效率与质量都上台阶。

  • 内容生产：选题 / 写作 / 审核 三只虾协作
  • 短视频：生产 Agent + 拆解 Agent 并行
提示设计原则：职责单一、接口清晰、人工在关键节点把关。
进阶篇自动化可靠性实践

从「手动跑一次」到「定时稳定跑」，要处理失败、超时与通知。

可靠性清单

  • 明确失败时的动作（通知而非静默）
  • 设置重试与超时边界
  • 保留可审计的运行日志
注意老田偏好：任务失败时发企业微信消息通知，而不是静默失败或自动重试。
进阶篇知识库双备份体系

交付物本地存一份，乐享知识库再存一份，防止单点丢失。

  • 本地：实战笔记 / 月报系统目录
  • 云端：乐享知识库对应空间
  • 命名与结构两端保持一致
提示每次交付主动提醒：记得双备份。

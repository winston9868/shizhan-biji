WB案例月度工作汇报自动生成

月底最头疼的事之一：把零散工作汇总成结构化的月报。用 WorkBuddy + 模板，半小时变三分钟。

做法

  • 维护一份每日日报（YYYY-MM/YYYY-MM-DD.md）
  • 月底运行生成脚本，聚合成月报
  • 自动推送企微群 + 邮件
提示老田已落地：自动化 ID automation-1782695947091，每月最后一天 18:00 触发。
WB案例培训方案一键成文

面向企业微信 / WorkBuddy 的客户培训，方案有稳定结构。用公文标准排版 Skill 直接出 Word。

结构

  • 培训背景与目标
  • 课程大纲与课时
  • 实操演练设计
  • 考核与后续
说明排版遵循：大标题方正小标宋、一级标题黑体、正文仿宋、1.5 倍行距（见 tianwei-word-formatter）。
WB案例销售数据透视分析

拿到一张杂乱的销售明细，让它快速产出透视表、趋势与异常项。

产出

  • 按区域 / 产品 / 月份的透视
  • 同比环比趋势
  • 异常值提示
提示图表需内嵌，避免依赖外部 CDN（老田本机访问 jsdelivr 不通）。

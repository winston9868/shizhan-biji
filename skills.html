公文标准排版 v1.3

热门公文排版已落地
①技能概述

将 Markdown 或纯文本内容按 GB/T 9704 路线一键排版为 Word：大标题方正小标宋简体二号、一级标题黑体三号、二级标题楷体_GB2312、正文仿宋_GB2312四号，1.5 倍行距，页边距上37mm/下35mm/左28mm/右26mm。

②部署方法
  1. 在 WorkBuddy 技能市场搜索「tianwei-word-formatter」
  2. 一键加载到当前任务或加入全局技能库
  3. 确保系统已安装方正小标宋、仿宋_GB2312、楷体_GB2312（缺字体时自动回退宋体/楷体/仿宋）
  4. 首次使用先用测试文档验证字体回退与页边距效果
③使用步骤
  1. 用 Markdown 准备正文：# 大标题、## 一级标题、### 二级标题、正文段落
  2. 输入指令：「用公文标准排版把以下内容生成 Word」
  3. 检查页边距、行距、标题层级与页脚页码
  4. 保存 .docx 并双备份到本地 + 乐享知识库
④示例指令
用公文标准排版生成一份《企业微信管理员培训方案》Word 文档，包含培训背景、课程大纲、实操演练、考核方式四个部分，落款右对齐。
⑤应用场景
月度/年度工作汇报快速成文
客户培训方案、实施方案正式交付
内部通知、会议纪要等公文样式文档

老田写作风格

写作润色已落地
①技能概述

把通用 AI 输出转换成老田的口吻：日常闲聊、工作讨论、正式交付、散文四档语域自动切换；内置 11 维风格量化、去 AI 味规则、五步写作框架与平台适配（公众号/小红书/知乎/头条）。

②部署方法
  1. 在 WorkBuddy 技能市场搜索「tianwei-style」
  2. 加载后输入 /skill 激活老田风格模式
  3. 告诉它当前场景（日常/工作/正式/散文）与目标平台
  4. 首次使用可先用一段自己的旧文做风格校准
③使用步骤
  1. 明确文章主题、目标读者与发布平台
  2. 输入指令：「用我的风格写一篇关于 XX 的文章，语域：工作讨论」
  3. AI 按选题→大纲→初稿→润色→平台改写五步输出
  4. 对不满意段落圈出来要求「再老田一点」或「更正式」
④示例指令
用我的风格写一篇关于「企业微信客户联系功能」的工作讨论文，面向销售团队，要求口语化、有网感但不浮夸，800 字左右。
⑤应用场景
朋友圈/社群推广文案快速出稿
公众号、小红书、知乎多平台改写
商务邮件、方案前言去 AI 味润色

月度报告生成

热门自动化运行中
①技能概述

基于固定格式的日报（YYYY-MM/YYYY-MM-DD.md），月底自动汇总工作事项、产出成果与下月计划，生成公文标准排版月报，并推送到企业微信群与 QQ 邮箱。

②部署方法
  1. 确认日报目录结构：月报系统/YYYY-MM/YYYY-MM-DD.md
  2. 配置自动化任务 automation-1782695947091，每月最后一天 18:00 触发
  3. 绑定企微群 webhook key 与 QQ 邮箱 alias_id
  4. 设置失败通知到企业微信，而非静默重试
③使用步骤
  1. 每天按模板填写日报
  2. 月底自动化脚本读取当月所有日报
  3. 聚合关键成果、数据与待办，生成月报 Word
  4. 自动上传文件到企微群并发送邮件副本
④示例指令
运行月报自动化，生成本月工作月报并推送到「销售团队」企微群和 986898476@qq.com。
⑤应用场景
销售/顾问岗位月度汇报
项目团队月底复盘
个人工作日志自动归档

企微文档管理

企业微信已落地
①技能概述

通过 wecomcli-doc 连接器操作企业微信在线文档：按 docid 或文档 URL 读取 Markdown 内容、覆写正文、新建空白文档。适合把本地报告同步到团队知识库。

②部署方法
  1. 确保 WorkBuddy 已安装并授权 wecom 连接器
  2. 在技能市场加载「企业微信文档」skill
  3. 确认当前账号有目标文档的编辑权限
  4. 测试读取一篇已有文档验证连通性
③使用步骤
  1. 提供文档 URL 或 docid
  2. 输入读取/覆写/新建指令
  3. 核对转换后的 Markdown 与原文格式
  4. 覆写前建议先本地备份
④示例指令
读取这篇企微文档 https://work.weixin.qq.com/... 的内容，提取要点后更新到本地月报。
⑤应用场景
团队周报/月报统一归档到企微文档
客户交付物云端双备份
会议纪要在线协同编辑

QQ 邮箱操作

邮箱通知已落地
①技能概述

通过 qq-mail 连接器收发 QQ 邮件。发送遵循老田规范：先 GetMe 取 alias_id、分两步走（Phase 1 拿 confirmation_token，Phase 2 发送）、正文控制在 500 字以内、to 字段只传 email。

②部署方法
  1. 确保 WorkBuddy 已授权 qq-mail 连接器
  2. 加载「qq-mail」skill
  3. 首次发送前调用 GetMe 获取最新 alias_id
  4. 确认 QQ 邮箱在网页端已登录且可用
③使用步骤
  1. 发邮件前先调用 GetMe 刷新 alias_id
  2. Phase 1：不带 confirmation_token 获取 token
  3. Phase 2：5 分钟内携带 token 正式发送
  4. 正文超过 500 字时分段或转附件
④示例指令
给 zhangsan@example.com 发一封邮件，主题是「月报已生成」，正文 300 字以内，附件为本月月报.docx。
⑤应用场景
月报、日报自动邮件抄送
客户正式交付物发送
群发通知但需控制正文长度

企微消息

企业微信已落地
①技能概述

通过 wecomcli-msg 连接器拉取企业微信会话与消息记录，支持文本/图片/文件/语音/视频类型；也可向指定会话发送文本消息，常用于自动化简报推送。

②部署方法
  1. 确保 WorkBuddy 已授权 wecom 连接器
  2. 加载「wecomcli-msg」skill
  3. 确认机器人账号在目标群/会话中
  4. 测试拉取最近 10 条消息验证权限
③使用步骤
  1. 指定会话或群名称
  2. 选择拉取记录或发送消息
  3. 如发送文件，先通过 upload_media 获取 media_id
  4. 检查消息是否成功到达
④示例指令
拉取「销售团队」群最近 50 条消息，汇总今日客户反馈与待办。
⑤应用场景
每日资讯简报自动推送到企微群
多群消息汇总成日报
客户群关键信息自动提取

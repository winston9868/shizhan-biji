公文标准排版 v1.3

热门公文排版已落地
①技能概述

将 Markdown 或纯文本内容按 GB/T 9704 路线一键排版为 Word：大标题方正小标宋简体二号、一级标题黑体三号、二级标题楷体_GB2312、正文仿宋_GB2312四号，1.5 倍行距，页边距上37mm/下35mm/左28mm/右26mm。

②部署方法
  1. 在 WorkBuddy 技能市场搜索「tianwei-word-formatter」
  2. 一键加载到当前任务或加入全局技能库
  3. 确保系统已安装方正小标宋、仿宋_GB2312、楷体_GB2312（缺字体时自动回退宋体/楷体/仿宋）
  4. 首次使用先用测试文档验证字体回退与页边距效果
③使用步骤
  1. 用 Markdown 准备正文：# 大标题、## 一级标题、### 二级标题、正文段落
  2. 输入指令：「用公文标准排版把以下内容生成 Word」
  3. 检查页边距、行距、标题层级与页脚页码
  4. 保存 .docx 并双备份到本地 + 乐享知识库
④示例指令
用公文标准排版生成一份《企业微信管理员培训方案》Word 文档，包含培训背景、课程大纲、实操演练、考核方式四个部分，落款右对齐。
⑤应用场景
月度/年度工作汇报快速成文
客户培训方案、实施方案正式交付
内部通知、会议纪要等公文样式文档

QQ 邮箱操作

邮箱通知已落地
①技能概述

通过 qq-mail 连接器收发 QQ 邮件。发送遵循老田规范：先 GetMe 取 alias_id、分两步走（Phase 1 拿 confirmation_token，Phase 2 发送）、正文控制在 500 字以内、to 字段只传 email。

②部署方法
  1. 确保 WorkBuddy 已授权 qq-mail 连接器
  2. 加载「qq-mail」skill
  3. 首次发送前调用 GetMe 获取最新 alias_id
  4. 确认 QQ 邮箱在网页端已登录且可用
③使用步骤
  1. 发邮件前先调用 GetMe 刷新 alias_id
  2. Phase 1：不带 confirmation_token 获取 token
  3. Phase 2：5 分钟内携带 token 正式发送
  4. 正文超过 500 字时分段或转附件
④示例指令
给 zhangsan@example.com 发一封邮件，主题是「月报已生成」，正文 300 字以内，附件为本月月报.docx。
⑤应用场景
月报、日报自动邮件抄送
客户正式交付物发送
群发通知但需控制正文长度

③使用步骤
  1. 关键数据整理成 markdown 消息直接推送
  2. 文件先用 Python 脚本 upload_media 取 media_id
  3. 再 POST send 发 file 类型消息
  4. 群成员下载附件用浏览器查看全貌
④示例指令
把这份月度经营分析.html 推送到「销售团队」企微群，并同步发一条 markdown 摘要列出三个关键指标。

随手记 note-capture

效率工具已落地
①技能概述

对话中流露保存/记忆/提醒意图即自动触发：内容写入个人写作系统 Markdown 库，自动判断类型并记录标题、类型标签、创建时间、来源对话摘要与正文；含链接时额外抓取摘要一并保存，存好后一句话告知。

②部署方法
  1. 在技能库加载「note-capture」skill
  2. 设定写作系统根目录（content 文件夹）
  3. 确认触发词表（帮我记住/记一笔/提醒我等）
  4. 试存一条验证文件命名与归档结构
③使用步骤
  1. 对话中说「帮我记住 XX」或「这个值得记录」
  2. AI 自动判断类型（笔记/灵感/待办/资源）
  3. 结构化写入写作系统对应目录
  4. 回一句确认，不打断当前对话
④示例指令
帮我记住：瑞升工贸的 IT 负责人下周三上午有空，拜访时重点聊云服务器迁移成本。
⑤应用场景
客户沟通要点随手归档
灵感与选题素材积累
口头待办不遗漏

沉睡客户激活包

销售获客已落地
①技能概述

针对企微好友多但转化低的 B 端销售场景：按行业设计激活钩子资料（Word/PDF 指南）、分层触达话术和 Excel 测试追踪表。核心原则：价值先行、分层触达、先选 50~100 人小步测试、数据驱动迭代（发送/回复/意向/成交全程记录）。

②部署方法
  1. 在技能库加载「dormant-customer-activation」skill
  2. 梳理现有沉睡好友规模与主攻行业
  3. 确认历史成交客户画像
  4. 准备好企微侧发送通道
③使用步骤
  1. 确认行业与销售现状（卡在找不到/聊不动/成交难）
  2. 生成行业钩子资料：《行业+痛点+可量化结果+方法》
  3. 输出分层激活话术与跟进 SOP
  4. 用追踪表跑 50~100 人测试，按数据迭代
④示例指令
我企微里有 800 个制造业沉睡好友，帮我做一套激活包：钩子资料、首触话术和测试追踪表。
⑤应用场景
企微存量好友二次激活
新产品线向老客户渗透
代理商销售团队标准化获客

WorkBuddy 推广文案

内容生产已落地
①技能概述

WorkBuddy 产品多渠道营销文案定制技能：围绕降本增效与开箱即用两大核心卖点，按渠道人群定制三版输出——公众号长文版面向企业决策者、小红书种草版面向职场人士、朋友圈短文案做极简传播。

②部署方法
  1. 在技能库加载「workbuddy-promo-copy」skill
  2. 明确本次推广的核心卖点与目标人群
  3. 可叠加「老田写作风格」去 AI 味
  4. 准备好配图素材（可配合海报技能）
③使用步骤
  1. 说明推广主题与投放渠道
  2. AI 按渠道输出对应版本文案
  3. 对标题与钩子句做打开率打磨
  4. 终稿过一遍审核虾再发布
④示例指令
围绕「WorkBuddy 自动生成月报」写三版推广文案：公众号版给企业老板看，小红书版给行政文员看，朋友圈版 50 字以内。
⑤应用场景
产品发布与功能更新宣传
代理商朋友圈日常种草
线下沙龙活动引流文案

技能安装安全审计

效率工具已落地
①技能概述

安装 SkillHub / GitHub / 社区来源技能的标准流程：强制「先安全审计、后安装」硬顺序，静态审查 SKILL.md 及配套脚本是否含 curl|bash、os.system、凭证外送、未锁版本依赖等风险，确认安全后再落地到技能目录，Python 依赖进虚拟环境并锁版本。

②部署方法
  1. 在技能库加载「skill-install-audit」skill
  2. 设定风险分级标准（P0 强警告 / P1 提示确认）
  3. 准备虚拟环境用于隔离安装依赖
  4. 把它设为所有外部技能安装的前置门禁
③使用步骤
  1. 拿到外部技能的仓库地址或压缩包
  2. 静态审查 SKILL.md 与 scripts/ 全部文件
  3. 输出审计报告：风险项 + 分级 + 建议
  4. 确认安全后按稳健方式落地安装
④示例指令
从 GitHub 装这个 pdf-tools 技能之前，先做一遍安全审计，重点查有没有外发凭证和危险命令。
⑤应用场景
安装社区/第三方来源技能前把关
批量迁移技能库时统一体检
团队内技能分发的安全规范

文件批量重命名

效率工具已落地
①技能概述

把散乱命名的文件统一为「日期_主题_类型.扩展名」格式：执行前先输出改名预览清单，自动处理重名冲突，改名前做安全备份，小批量执行随时可回退，不碰目标目录以外的文件。

②部署方法
  1. 在技能库加载「file-batch-rename」skill
  2. 指定目标目录与命名规则
  3. 确认备份目录位置
  4. 先用少量文件试跑验证规则
③使用步骤
  1. 指定要整理的文件夹
  2. AI 输出改名前后对照预览表
  3. 确认无误后执行（自动备份原文件）
  4. 抽查结果，异常可从备份恢复
④示例指令
把 E:\workbuddy\案例 目录下的文件按「日期_客户名_文档类型」格式批量重命名，先给我预览。
⑤应用场景
客户交付物归档整理
下载目录周期性清理规范化
项目移交前的文件标准化

腾讯云风格海报提示词

内容生产已落地
①技能概述

腾讯云官方品牌视觉（腾云驾雾风格）的图像提示词生成器：先分析文章/内容，生成 5 个封面选题供挑选，选定后输出可直接投喂图像模型的高质量提示词。覆盖公众号封面、活动物料、朋友圈海报、产品图、信息图等场景。

②部署方法
  1. 在技能库加载「tencent-cloud-style-poster-generator」skill
  2. 准备要配图的文章或活动信息
  3. 确认出图通道（内置 ImageGen 或第三方）
  4. 首次使用先出一张验证风格符合预期
③使用步骤
  1. 提供文章内容或海报主题
  2. AI 分析后给出 5 个封面选题
  3. 5 选 1 确定方向
  4. 输出完整图像提示词，直接生成海报
④示例指令
给这篇《WorkBuddy 月报自动化实战》文章配公众号封面，腾讯云风格，先给我 5 个选题。
⑤应用场景
公众号/博客封面图量产
活动物料与朋友圈海报
产品宣传视觉统一风格
